# SOS 110 Mastery

Interactive mastery homework for **SOS 110: Introduction to Sustainability** (Arizona State University).
The first module is **Chapter 11: Climate**, built from the Chapter 11 lecture deck
(<https://ryanpcornell.github.io/sos110-chapter-11/>).

Live site: <https://ryanpcornell.github.io/sos110-mastery/>

## How it works
- **20 concepts per chapter**, each with **3–4 versions** of its problem. A student masters a concept the first time
  they answer any version fully correctly. A miss shows the answer and explanation, opens the review resources, and
  offers a **new version** (not the same question again).
- **Problem types:** multiple choice, select-all, fill-in-the-blank (with numeric tolerance), ordering, sorting into bins,
  matching, figure choice, and visual interactives: chart reading (click a point on real data), sliders with live
  pictures (CO₂ → temperature model, CO₂ record, pH and hydrogen ions, dollars per tonne), drag-to-build bar charts,
  and diagram labeling.
- **Resources:** each concept has review notes, a figure, key terms and links to the exact lecture slides. They start
  folded (try first) and open on request, after a miss, or once the concept is mastered.
- **Grades:** chapter grade = concepts mastered ÷ 20. The gradebook shows status, every try, mastery dates, first-try
  accuracy and practice time, and prints cleanly to PDF.
- **Storage:** progress is kept in the browser (localStorage). A "save code" moves it between computers. Nothing is
  sent to a server.

## Files
- `index.html`: shell
- `css/mastery.css`: design system (One Sky parchment palette + the deck's warming stripes)
- `js/charts.js`: hand-drawn SVG charts with click-to-pick
- `js/widgets.js`: problem types
- `js/bank-ch11.js`: Chapter 11 concepts, versions, explanations and resources
- `js/data-ch11.js`: chart data, generated by `tools/build_data.py` from the deck's data files
- `js/app.js`: routing, mastery logic, gradebook, save codes

## Adding a chapter
Write `js/bank-chNN.js` registering `window.MB_CHAPTERS.chNN = {id, num, roman, title, subtitle, deck, sections, concepts}`
(same shape as Chapter 11), add its `<script>` tag to `index.html`, and it appears on the course page.
